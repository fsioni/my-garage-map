# Changelog

Notable changes to Garage MCP are documented here.

## Unreleased

### Added

- Initial public release of the local stdio MCP server.
- Vehicle, mileage, maintenance, parts, expense, reminder, document, and summary tools.
- Read-only MCP resources for vehicle history and summaries.
- SQLite persistence with versioned migrations and transactional writes.
- Strict validation, typed Effect errors, and safe MCP error responses.
- Comprehensive unit, property, integration, contract, and stdio lifecycle tests.
- Open source community, security, and contribution documentation.

### Security

- Dependency update automation, dependency review, CodeQL scanning, immutable GitHub Action
  references, and explicit least-privilege workflow permissions.
