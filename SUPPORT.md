# Support

Use the repository's issue forms for help:

- choose **Question or support** for setup and usage questions;
- choose **Bug report** for reproducible incorrect behavior;
- choose **Feature request** for product suggestions.

Before posting, check the [README](./README.md), existing issues, and
[architecture documentation](./ARCHITECTURE.md).

This is a volunteer-maintained project, so response times are not guaranteed. Never include
real VINs, registration numbers, document paths, databases, credentials, or other private data
in a public issue.

Security vulnerabilities must be reported privately according to [SECURITY.md](./SECURITY.md).
